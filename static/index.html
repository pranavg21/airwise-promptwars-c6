Data origin, accuracy and uncertainty

Open-Meteo air quality API uses Copernicus Atmosphere Monitoring Service (CAMS) modeled products. Global spatial resolution is coarse relative to roads and neighborhoods. It is not a local sensor, official CPCB measurement, indoor air sample or street-level route forecast. Modeled values and updates can be delayed. This app displays the US AQI scale, which is not directly interchangeable with India's CPCB AQI.

Forecast comparisons use model estimates, not a measured personal inhaled dose. AQI categories are interpreted conservatively for the person's context; health suggestions are not individualized medical advice.
